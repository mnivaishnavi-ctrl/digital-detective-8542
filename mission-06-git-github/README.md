## Task 6.1 — Basic Git workflow

| Git operation | What it does |
|---|---|
| `git status` | Shows which files have changed and whether they are staged. |
| `git add mission-06-git-github/README.md` | Selects this README change for the next commit. |
| `git commit -m "Document basic Git workflow"` | Saves the staged change in the repository’s history. |
| `git log -5 --oneline` | Shows the five most recent commits in a short format. |

Staging selects changes for a commit. Committing saves the selected changes in Git history.
