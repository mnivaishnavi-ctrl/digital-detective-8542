| Git operation | What it does |
|---|---|
| `git status` | Shows which files have changed and whether they are staged. |

## Task 6.3 – Create a Pull Request

### What is a Pull Request?

A Pull Request (PR) is a request to merge changes from one branch into another branch. It allows team members to review changes before they become part of the main project.

### Steps Performed

1. Opened my repository on GitHub.
2. Compared the `update-about` branch with the `main` branch.
3. Created a Pull Request from `update-about` into `main`.
4. Added a description explaining the README changes.
5. Reviewed the changed files.

### Why Are Branches and Pull Requests Useful?

- **Branch:** Allows developers to work on changes separately without directly modifying the main branch.
- **Pull Request:** Allows others to review and discuss changes before merging.
- They help teams collaborate and maintain project quality.

### Task 6.4 — Git command glossary

| Git operation | Meaning |
|---|---|
| git init | Starts a new Git repository. |
| git status | Shows which files have changed. |
| git add | Selects files for the next commit. |
| git commit | Saves selected changes in Git history. |
| git log | Shows earlier commits. |
| git branch | Shows branches or creates a branch. |
| git switch | Changes to another branch. |
| git push | Sends commits to GitHub. |
| git pull | Gets the latest changes from GitHub. |
